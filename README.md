# Frost Breakout

A ready-to-run React + Vite arcade game using HTML Canvas.

## Run

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.

## Controls

- Arrow Left / Right or A / D: move paddle
- Space: launch ball / resume
- P: pause
- Mouse / touch: move paddle and launch
- Top-right buttons: sound, pause, restart

Features: 8 levels, combo multiplier, lives, power-ups, particle/frost effects, responsive canvas, sound effects, pause/game-over/win states.
